**已验证的客观机制结论**：
1. **`Cosine unique_bonus` 退火（`2.0 -> 0.0`）的收口与防换血价值**：相比常值 `UW=2.0`（`Old R4_D4`），余弦退火消除了训练后期为赚取新词分而丢弃原优质桶的“大换血”（`Lost PM` 从 `183.5` 压低至 `108.9`，唯一检索桶从 `22.8 万` 恢复至 `31.0 万`）；在静态直训后半程（`S170 -> S234`），退火在不损 `PM Density`（`500.5 -> 499.3`）的前提下进一步剔除 `83` 个粗糙大桶坏词，使 `PM Good Rate` 从 `39.25%` 提纯至 `42.01%`。
2. **自适应棘轮 Dinkelbach 水位 + 纯 $\sqrt{n}$ 分母**：以每查询自身纯度水位 $p_{\text{ref},m}(q) = \max(p_{\text{base},m}, p_{\text{group},m})$ 中心化词回报，赋予坏词真实负成本，将动态 `PM Good Rate` 从 `36.4%` 拉升至 **`45.54%`**、静态 `PM Good Rate` 从 `32.1%` 拉升至 **`42.01%`**；同时将分母从 $\sqrt{10\max(n,10)}$ 改为纯 $\sqrt{n}$，消除了负分条件下 `k_floor=10` 反而减轻小死桶惩罚的符号反转陷阱。
3. **`dink2` 三项改动的严格单变量证伪与回退**：在 32 卡 468 步严格单变量对照（`dink1` vs `dink2`）中，给 `unique_bonus` 乘 $(1 - p_{\text{ref},m})$ 直接腰斩了前中期对中等纯度大富桶的探索推力（静态 `Uniq PM / SM` 分别减少 `14.4 / 30.9`），且 `TREE_CREDIT_TOP_K=(8,4,1)` 与 `leaf-std` 归一化未能改善终局子树坍缩（`uniq_L3: 19.05 -> 17.62`，密度全线下降），故已干净回退（仅保留防负优势梯度尖峰的 `--eps-clip-c 3.0`）。
4. **静态部署场景下的训练–评测环境对齐（`--doc2k-mode disabled`）与无 `KL=0` 过拟合**：开 `doc2k` 训练再抽走 `overlay` 测静态索引存在约 `30` 点密度损失（动态 `doc2k` 富化的小桶与裁剪到 `32` 词的肥桶在静态下打回原形）；直接在静态 `part25` 上训练（`dink1-nodoc2k`）后，全程单调收敛且无任何后半程退化（证明可验证受限动作空间 + 15M 单遍流下不存在所谓“`KL=0` 过拟合”）。

### 1.2 `~140–150` 步全面横盘的纯 RL 机制实证：策略熵跌破 $H^* = \ln 64$ 与模式坍缩（Mode Collapse）

对齐三组 64 卡全量实验（`Main Exp`、`dink2-nodoc2k`、`dink1-nodoc2k`，固定学习率 `lr = 2e-6`）的完整训练轨迹发现：无论是否启用 Dinkelbach 或 `doc2k`，训练指标与离线 `PM Density` 均在 **`Step 120–150` 附近进入平台期**（例如 `dink1-nodoc2k` 在线 `pm_pass` 从 `S0: 16.16% -> S120: 24.52% -> S140: 25.14%` 后，在 `S140 -> S233` 的 94 步内横盘于 `25.04%~25.37%`；离线 `PM Density` 在 `S170: 500.5 -> S210: 502.8 -> S234: 499.3` 同样完全横盘；32 卡 468 步实验的静态密度峰值亦停在同一区间 `515~523`）。

由于默认 `--entropy-coef 0` 下训练框架未计算策略熵，直接加载 `dink1-nodoc2k` 从 `Step 0` 至 `Step 234` 的 7 个里程碑权重，在固定评测查询上实测 **4 层条件策略熵 $H(d_0..d_3)$、前 16/64 束占全库 `8,853 万` 桶的总概率质量比例、以及 `Z4` 512 束在线采样实际覆盖的二级类目数**：

**纯 RL 机制归因结论**：
1. **表象剥离（在线 512 无放回 `pm_pass` 的集合均值边界）**：在线 Rollout 强制无放回采满 `512` 个不同桶，而静态索引单个相关 `(c0, c1)` 邻域内好桶总数仅数十个（实测 `S234` 确定性 `Top-512` 全池平均合格率本来即为 `~25%` PM / `~52%` SM）；当 `c0, c1` 路由在前 135 步收敛后，无放回 512 集合均值天然触顶。
2. **实质根因：总策略熵在 `~Step 140` 跌破 `Top-64` 最小容量阈值 $H^* = \ln 64 \approx 4.16\text{ nats}$，触发单点 RL 模式坍缩（Mode Collapse）**：
   - 确定性 `Beam-64` 要选出 64 个平权优质桶，策略分布至少需要支撑 64 个有效模式（对应均匀分布最小熵 $\ln 64 \approx 4.16$ nats，每桶概率 $\approx 1/64 = 1.56\%$）。
   - 在 `--entropy-coef 0 --kl-coef 0` 下，标准策略梯度优化的是单次抽样期望 $\mathbb{E}_{d \sim \pi}[R(d)]$，其理论收敛不动点是将 `100%` 概率集中于极少数最高分路径。前 120 步有高 `unique_weight (> 1.0)` 充当外部探索推力，总熵保持在 `4.27` nats（`71.5` 个有效模式，`Z4` 覆盖 L2 类目扩张至 `7.6`）；
   - **`Step 120 -> 170`（即 `~140–150` 步拐点）**：随着 `unique_weight` 退潮，总熵跌破 `4.16` nats 一路坍缩至 `3.07` nats（有效模式数仅剩 **`21.5` 个**，与离线 `uniq_L3 = 24.7` 严格对应），**仅 `Top-16` 就吞噬了全库 `86.0% -> 92.4%` 的总概率质量**，而 **`Rank 65..512` 整整 448 个桶合计仅剩 `0.6%` 概率**。
3. **Mode Collapse 引发的双重自锁**：
   - **在线探索支撑集自锁**：固定采样温度 `T = (0.20, 0.25, 0.60, 0.80)` 无法抵御策略自身 logit 极差拉大，512 束采样收缩到仅 `5.6` 个二级类目内打转（`r_std` 从 `1.12` 降至 `0.61`），外部优质子树失去采样曝光；
   - **Softmax 零和挤占堵死 `Rank 17..64`**：头部十余个父节点的单步概率冲上 `0.95 / 0.77`，通过 Softmax 归一化压低了第 `20..50` 棵次优好 `c2` 子树的前缀概率，使全局 `Beam-64` 搜索在 `Rank 17..64` 中填入头部父节点连带的 `<10` 小兄弟桶（占 `64.0%`），把原本已在 `Top-512` 内的 `17.1` 个高产富桶挡在前 64 之外。

### 5.3 核心实验结论与对主实验（64 卡）的配置指导

1. **三项机制改进各自独立有效，且在 `M3` 中产生强正协同（PM Density 增益比 `B0` 提升 `+45%`）**：
   - 在仅消费 `80,000` 条训练 query（占 1500 万全量数据的 `0.53%`，相当于 64 卡主实验的 `1.25` 步！）的情况下：
     - 对照组 `B0` 将 PM `good_density` 从 `297.92` 提升至 `303.91`（**`+5.99`**），PM `unique_good_density` 达 **`10.652`**；
     - 单独开启 **`M1`（按层退火采样 + L3/L2 集中填桶）** 将 PM `good_density` 增益扩大至 **`+7.08`（比 `B0` 高 `+18.2%`）**，且 Mapping-Only 的 `PM_Uniq_D` 达到 `B0` 的 **`4.1 倍`（`0.512 vs 0.126`）**；
     - 单独开启 **`M2`（按层因果树归因）** 在 `T=0.4` 窄探索下将 PM `good_density` 增益提升至 **`+6.35`**，SM `unique_good_density` 提升至 **`22.171`**（优于 `B0` 的 `21.855`）；
     - 组合全部三项机制的 **`M3`（`M1 + M2 + PM-Primary`）** 在**所有核心指标上全面夺冠**：
       - **PM Good Density 增益达 `+8.69`（`297.92 -> 306.60`，比 `B0` 的 `+5.99` 提升 `+45.1%`！）**；
       - **PM Keyword Good Rate 达 `32.78%`（全场最高，比 Baseline `+1.52pt`，比 `B0` `+0.31pt`）**；
       - **PM Unique Good Density 达 `12.177`（比 `B0` 的 `10.652` 提升 `+14.3%`）**；
       - **难得的双赢（No SM Trade-off Loss）**：尽管 `M3` 将奖励权重向 PM 倾斜为 `1.5 : 0.5`，但因为按层退火 + 因果树归因 + PM 主导引导模型找到了真正同时满足 PM 与 SM 的高质量 `A4_pure_rich` 富桶，**`M3` 的 SM Good Density（`579.54`, `+11.31`）与 SM Unique Good Density（`22.901`）同样高居全场第一**！
2. **为什么 `M1 + M2 + PM-Primary`（`M3`）有显著协同效应？**
   - 单独用 `M1`（按层退火 `T=(0.2, 0.25, 0.6, 0.8)`）时，后两层 `(c2, c3)` 的高温展开虽然把同子树下的 `A4_pure_rich` 富好桶采出来了（多采出 $2.6\times$），但也把同 `(c0, c1, c2)` 前缀下的大量零分兄弟叶子一起采进了 512 样本组——如果不开启 `M2`（因果树归因），这些同前缀零分兄弟叶子在标量树归因下会白嫖富桶的正梯度（导致 `M1` 的 Policy-Only `PM_Uniq_D` 从 `10.52` 轻微降至 `10.02`）。
   - 而一旦在 `M3` 中将 **`M1`（子树内高温探索）+ `M2`（叶子层切断前缀搭便车）+ `PM-Primary`（抑制 25% 纯 SM 桶干扰）** 结合：高温采样负责在同一 `(c0, c1, c2)` 前缀下同时召回富好桶与零分兄弟桶，而因果树归因 + PM 主导奖励则在最后一层 $t=3$ 给富好桶强正梯度、给同前缀零分桶和纯 SM 桶负梯度，从而让 Policy-Only `PM_Dens` 跃升至 `+8.23`（`+40%` vs `B0`），同时 Mapping-Only `PM_Uniq_D` 提升 `4.2 倍`！

2. **扩至 `Top-128 / 256 / 512` 后密度亏损单调放大，并非前排重排**：`Fix Step 105` 不仅在 `Top-64` 亏损 `-112.1`，在 `65~128`、`129~256`、`257~512` 每个区间均比 `Baseline` 同档位更薄、纯度更低（来自 `Base > 512` 的贫瘠桶在 `Fix` 四个档位中分别占 `29.9% / 49.9% / 62.1% / 74.9%`），而 `Baseline Top-64` 中有 `17.00` 个富桶（`Baseline 65~128` 中更有 `30.98/64 = 48.4%`）被直接挤出 `Top-512` 之外。
3. **三项底层机制共同造成了静态索引下的逆向淘汰**：
   - **组内 `1 / freq(k)` 词频稀释与静态 `UNIQUE_WEIGHT = 2.0` 的乘数剪刀差**：`Baseline` 头部富桶内的高频好词跨兄弟桶高度共享（仅 `Top-64` 内 `Rank 1~16` 词均出现 `2.36×`）且 `unique_bonus = 0`，而 `> 512` 边缘碎桶新词多为孤立出现（`freq = 1`）且获双倍加分。在全量 `3,320` 条 `en-us` 桶池上实算含 `1 / freq(k)` 的真实单桶奖励：当 `UW = 2.0` 时，`Added` 碎桶得分在 `max(n,10)` 与 `sqrt_floor` 下分别反超 `Dropped` 原版好桶 **`+39.4%`**（`0.5114` vs. `0.3668`）与 **`+23.0%`**（`0.8383` vs. `0.6818`）；而仅将 `UW` 置 `0`（仍保留 `1 / freq(k)`），激励符号即彻底反转为 `Added` 低于 `Dropped` **`-26.6%`**（`0.5005` vs. `0.6818`，扩满同子树 `512` 桶仍低 `-22.2%`）。
   - **`Qwen3-4B` 查询编码器在无约束长训下的表征漂移主导了崩盘幅度**：固定 `Baseline` 的 `Qwen3-4B` Encoder、仅加载 `Fix Step 105` 的 6 层 T5 Decoder 时，`Top-64` 重合度高达 `58.97 / 64`（`0` 个桶来自 `> 512`），`en-us` `Top-64 / Top-512` PM Density 反升 `+7.49 / +16.67`；一旦换上漂移后的 `Qwen3-4B` Encoder，重合度骤降至 `22.41 / 64`，贡献了 `88%` 以上的密度跌幅。
   - **缺乏 `doc2k` 动态富化**：当表征漂移进入 `> 512` 区域后，静态索引无法将同组发现的好词沉淀至新头部桶，导致检索直接暴露于 `9.8` 词、`17.55%` 纯度的原始稀疏桶。

**全量 15M 长程观测与深层分析结论**：
1. **`Density` 翻倍增长但 `Keyword Good Rate` 在 `Step 104` 后长期停滞**：
   - `sqrt_floor + Z4 + RelGuidedDoc2k` 彻底扭转了 `en-us` 桶缩水（`en-us` PM Density 从 `435.52` 增至 `633.09`，非 `en-us` 从 `221.54` 增至 `615.78`，全集 PM Density 翻倍至 `621.03 (+112.3%)`）。
   - 但该密度增长主要由展开总词数 `#KW/Q` 翻倍（`810.1 -> 1,654.5`）驱动；`Combined PM Good Rate` 在 `Step 104` 达到 `36.79%`（仅较基线 `+5.70pt`）后停滞了整整 `364` 步（收于 `36.20%`），`SM Good Rate` 收于 `60.45%`（仅 `+3.18pt`，`en-us SM Rate` 末期回落至 `64.26%`）；剥离动态索引后的 **`Policy-Only PM Rate` 从 `Step 104` 的 `33.86%` 一路回落至 `Step 468` 的 `30.92%`（低于未训练基线 `31.09%`）**。
2. **跨查询“多义合桶悖论（Multi-Intent Polysemy）”解释了为何激进删词会损伤总词数与密度，`doc2k` 保护锁具有客观必要性**：
   - 实测被多条查询共享的大桶中，单条查询视角下约 `47%` 的未过阈值词并非无意义噪声，而是归属同一粗粒度桶内其他兄弟子意图的有效词——跨命中查询取并集后 **`88.58%` 的词至少对一条查询为真 PM 好词**，真正全查询零命中的死词仅占 `11.42%`，加之全库 `56.18%` 唯一词 `degree == 1`（误删即永久不可检索），直接解释了历史上短窗口激进删词为何导致 `#KW/Q` 与密度双降。
   - 同时，对比 `Step 468` 同一批检索桶在动态索引（`Combined`）与静态索引（`Policy-Only`）下的表现：`doc2k` 净增了 **`+142.36` 个 PM 好词**并净减了 **`-37.2` 个坏词**（`Mapping-Only PM Rate` 单调升至 `34.06%`），证明 `RelGuidedDoc2k` 本身是纯正向提纯贡献；但受多义词保活边界制约，单靠索引删词在原理上只能剔除极少数全查询真死词（约 `3.5%`），无法消除多意图合桶带来的陪跑词。
3. **`Good Rate` 停滞的根本原因是零坏词成本与静态新词加分驱动的“跨查询超级大桶合流坍缩（Hubness Collapse）”**：
   - 在未过阈值坏词零惩罚（成本为 `0`）、去重评估中好词跨桶高重叠而坏词低重叠、以及恒定 `UNIQUE_WEIGHT = 2.0` 的联合作用下，长程策略并未停留在高纯度细分专精桶（Baseline 中 `10..19` 词专精中桶天然 `PM/SM Rate` 达 `41.40% / 70.20%`），而是不断跨出原二级类目（`c1Keep` 从 `64.0` 跌至 `25.46 / 64`，非 `en-us` 跌至 `18.36 / 64`），将海量不同查询汇聚到少数多意图巨桶中。
   - 全量 10,000 条查询（`640,000` 个 Top-64 槽位）统计直接证实了这一坍缩：**唯一检索 DocID 数量从 `Baseline` 的 `504,702` 个（`78.86%`）单调萎缩 `-54.8%` 至 `Step 468` 的 `227,902` 个（`35.61%`），前 `1,000` 个高频 Hub 桶垄断的检索槽位比例从 `5.66%` 飙升 `3.85×` 至 `21.78%`**；每条查询在获取 `621.0` 个 PM 好词的同时，伴随吞下了多意图共享巨桶中属于其他子意图的 **`1,033.5` 个未过阈值陪跑词**（静态索引下达 `1,070.7` 个），从而将整体 `Keyword Good Rate` 锁定在平台期。
